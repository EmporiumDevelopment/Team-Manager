Team Manager · 6pm Esports

Privacy Policy

Effective 31 October 2026

Team Manager (“the bot”) is a Discord bot operated by 6pm Esports to manage the team's Discord server. This policy explains what information the bot handles, why, and how you can have it removed.

Information from TikTok

If a creator chooses to connect their TikTok account using “Login with TikTok”, the bot receives and stores:

  • The account's TikTok user ID (open ID) and display name.
  • Access and refresh tokens issued by TikTok, which let the bot read the account's list of public videos.
  • The upload time of the most recent video already announced, so the same video isn't announced twice.

The bot requests only the user.info.basic and video.list permissions. It uses them solely to detect new public videos and post an announcement (video title, cover image and link) in the team's Discord server. The bot cannot post, edit or delete anything on TikTok, and does not access private videos, messages, followers or any other account data.

Information from Discord

To run team features (roster, schedules, scrim availability, activity, earnings and logs) the bot stores Discord user, role, channel and message IDs, player names entered by server admins, and records admins create through the bot's commands.

How information is stored and shared

  • Data is stored in a private database used only by the bot.
  • We do not sell, rent or share this information with third parties, and do not use it for advertising.
  • Information is only shown inside the team's Discord server, as part of the features described above.

Retention and deletion

  • Running /tiktok disconnect deletes the stored TikTok tokens, user ID and display name immediately.
  • You can also revoke the bot's access at any time in the TikTok app under Settings and privacy → Security → Manage app permissions; the bot then stops checking for videos.
  • To have any other data about you removed, contact the 6pm Esports team through their Discord server.

Changes

If this policy changes, the updated version will be published on this page with a new effective date.

Contact

Questions about this policy can be sent to the 6pm Esports team through the 6pm Esports Discord server.
